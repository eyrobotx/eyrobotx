EYROBOTX — Frontend

İSTİFADƏ
1. ZIP faylını tam çıxarın.
2. index.html faylını brauzerdə açın.
   Alternativ: VS Code-da Live Server ilə başladın.
Heç bir paket quraşdırılması və build tələb olunmur.

FAYLLAR
index.html — saytın əsas quruluşu və menyu
style.css — bütün dizayn və mobil uyğunlaşma
script.js — məzmun, səhifə keçidləri, kurslar, modullar, layihələr, resurslar, axtarış
assets/eyrobotx-logo.png — təsdiqlənmiş loqo

MƏZMUNU DƏYİŞMƏK
script.js daxilində:
courseDetails — kurs modulları, alətlər və nəticələr
courses — kurs adları və qısa məlumat
serviceDetails — xidmətlərin məzmunu
projectLibrary — nümunə layihə istiqamətləri
learningResources — tədris yazıları
fullFaq — sual-cavab

Bölmələr #courses, #course/steam kimi hash keçidləri ilə açılır.
Ayrıca backend və verilənlər bazası yoxdur.
Əlaqə forması WhatsApp üçün müraciət mətni hazırlayır; göndərməyi istifadəçi təsdiqləyir.
Telefon və e-poçtu dəyişmək üçün index.html və script.js daxilində axtarıb yeniləyin.
Qiymətlər hələ verilmədiyi üçün saytda dəqiq məbləğ göstərilmir.
Bütün faylları birlikdə statik hostinqə yükləmək mümkündür.
